# E3272: статус проекта и передача контекста

Эта папка сводит в одном месте состояние проекта Huawei E3272s-153 / MegaFon
M150-2, ограничения переноса Linux и результаты проверки изменений upstream API
для ядра Linux 4.19. Это документация о доступных материалах и статическом
анализе, а не подтверждение собранной или работающей на устройстве системы.

## Состояние

- Локальный SDK включает распакованную прошивку `22.491.09.00.00`, исходники
  vendor Linux `2.6.35.7` для Balong Hi6920CS/V7R1, исходники userspace,
  инструменты распаковки/пересборки и документацию. SDK находится вне этого
  репозитория.
- В Windows-среде отсутствует исходный ARM toolchain Sourcery G++ Lite 4.5.1;
  ядро и userspace в этой среде не собирались. Сценарии SDK рассчитаны на
  Linux/WSL2/Docker.
- SDK содержит запись о результате проверки пересборки образа `10/10 PASS`.
  Эта проверка в рамках подготовки настоящих документов не запускалась
  повторно. Она не подтверждает сборку ядра, загрузку образа на устройство или
  успешную загрузку устройства.
- Для upstream Linux LTS локально был доступен shallow bare clone с тегом
  `v4.19.325`, commit `a67e7cdde7cc7984ae24c3c81a70dc1aa34424b1`. Полная история
  репозитория повторно не загружалась. Перечень API и границ версий приведён в
  [API-4.19.md](API-4.19.md).
- Современный kernel-порт не собран и не проверен загрузкой на аппаратуре;
  наличие исходников не означает наличия готового ПО. SSH не демонстрировался.

## Ограничения платформы

Целевая Android-среда — 32-битная `armeabi` с soft-float. Модемная часть
использует закрытую VxWorks/AMP IPC и контракт shared memory. Также существенны
совместимость имён и разметки NAND, vendor-формат YAFFS2, формат Android bootimg
и ограничения размеров разделов. Эти зависимости требуют отдельного
согласования; один лишь выбор более нового ядра их не решает.

Статический анализ исходников и образов не подтверждает состояние конкретного
экземпляра модема. VxWorks shell не является Linux shell или SSH. Физические
UART-площадки, распиновка и электрические уровни не подтверждены; не следует
подключаться к случайным контактам, подавать на них сигнал, менять NV/flash
или прошивать образы от родственных моделей на основании этих заметок.
