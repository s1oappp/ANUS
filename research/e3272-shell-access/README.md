# E3272: заметки об исследовании доступа к shell

Эта папка содержит исследовательские наработки о возможном доступе к shell на
Huawei E3272 и о сопоставлении с GPL-архивом для родственных устройств Balong.
Это статический анализ файлов и исходников, а не инструкция по прошивке или
переключению режимов.

## Документы

- [Анализ shell, USBL и родственного GPL BSP](analysis.md) — выводы, основания,
  уверенность, ограничения и безопасные дальнейшие шаги.

## Важное ограничение

Выводы о VxWorks shell и USB-профиле относятся к исследованному бинарнику USBL
E3272 и его статической конфигурации. Содержимое прошивки и активный профиль
текущего экземпляра устройства не проверялись чтением с устройства. Не прошивайте
образы и не отправляйте неизвестные команды переключения режима на основании
этих заметок.
