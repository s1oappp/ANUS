# 08. Характеристики E3272s‑153 из загрузчика (факты с адресами)

> Прямой ответ на вопрос «что именно записано в загрузчике». Все факты — из образа
> `usblsafe-327x.bin` (адреса VA = file_off − 0x3C0 + 0x30004000); внешние подтверждения
> помечены [web]; пробелы — честно перечислены в §6. Гипотезы помечены [гип].

## 2. Запись продукта E3272S‑153 (байт в байт из таблицы)

Таблица `huaweiProduct`, запись @VA **0x3012FCE0**, шаг записи **0x34 байт**:

```
+0x00: 00000301   id = (idMain<<8)|idSub → main=0x03, sub=0x01
+0x04: → 0x3012FF40  PRODUCT_NAME      "E3272S-153"
+0x08: → 0x3012FE84  PRODUCT_NAME_PLUS "MPWUDP"
+0x0C: → 0x3012FF4C  DLOAD_ID          "CH1E3272SM"
+0x10: → 0x3012FEA4  HW_VER            "B710S0"
+0x14: → 0x3012FF58  внутреннее имя    "E3272"
+0x18: 00960081      маска бэндов 0 (GU)      ← см. §4
+0x1C: 000800C4      маска бэндов 1 (LTE)     ← см. §4
+0x20..+0x30: нули
```

Геттеры рантайма: `BSP_GetSupportBands`@0x3000DB54 (отдаёт 3 слова: GU/LTELow/LTEHigh),
`BSP_GetSupportBandsForGu`@0x3000DBAC (2 u16 с маской). На живом устройстве вызов
`BSP_GetSupportBands` из shell печатает расшифровку — это способ получить окончательный
ответ по бэндам без реверса (docs/05 §5).

## 3. E3272S‑153 vs E3272S‑600: в чём реальная разница

Обе записи в таблице продуктов отличаются **только масками бэндов** — имя платы, DLOAD_ID,
внутреннее имя совпадают:

| Поле | E3272S‑153 (id 0x301) | E3272S‑600 (id 0x306) |
|---|---|---|
| PRODUCT_NAME | E3272S‑153 | E3272S‑600 |
| DLOAD_ID | CH1E3272SM | CH1E3272SM |
| HW_VER | B710S0 | B710S0 |
| внутреннее | E3272 | E3272 |
| бэнды0 (GU) | **0x00960081** | **0x00960091** |
| бэнды1 (LTE) | **0x000800C4** | **0x000000C5** |

⇒ «путаница с характеристиками» на уровне прошивки сводится к разным региональным
маскам бэндов; вся остальная «железная» идентификация у них одна и та же.

## 4. Расшифровка масок бэндов

### 4.1 LTE‑маска E3272S‑153: 0x000800C4 = биты {2, 6, 7, 19}

**Гипотеза маппинга** «бит N ↔ диапазон N+1»:
- бит 2 → **B3**, бит 6 → **B7**, бит 7 → **B8**, бит 19 → **B20**;
- внешние источники дают для E3272s‑153 спецификацию **B1/B3/B7/B8/B20**
  [web: игла.рф, balong_series] — совпадение по B3/B7/B8/B20 полное; B1 (бит 0) в маске
  статической таблицы **не выставлен** — либо B1 активируется рантаймом из NV
  (структура `BSP_GetSupportBandsForGu` накладывает маску `DAT_3000dd78` на поля продукта
  +0x30/+0x34), либо спецификация и заводская маска расходятся.

### 4.2 E3272S‑600: 0x000000C5 = биты {0, 2, 6, 7} → B1/B3/B7/B8, БЕЗ B20 (бит 19 чист)

⇒ заводская логика различия регионов воспроизводится масками: **153 = «Европа» (B20 есть),
600 = «Азия» (B20 нет)** — это и есть главный разрешаемый пункт путаницы.

### 4.3 GU‑маска E3272S‑153: 0x00960081 = биты {0, 7, 9, 10, 12, 15}

GSM 850/900/1800/1900 + UMTS B1/B8 [гип: соответствие бит→диапазоны для GU требует
калибровки по живому устройству; окончательный ответ — `BSP_GetSupportBands` в shell].

## 6. Чего в загрузчике НЕТ (честно)

1. **Частота CPU** — не зашита константой в образе; в вебе тоже не найдена
   [web: перебор запросов, негатив]. Определять на устройстве по регистрам CRG
   (0x90000000+) или по BogoMIPS рабочего ядра.
2. **Физический объём RAM** — в образе нет константы размера (маска окна 0x3FF00000 ≈ 1 ГБ —
   не объём). Внешние источники для V7R1 дают **128 МБ RAM** [web: balong_series];
   ядро USBL видит только ~24.7 МБ над 0x30000000 (`sysMemTop` = 0x301C4C30,
   DAT_300405FC) — остальное зарезервировано за DSP/модемными ядрами.
3. **Объём/геометрия NAND** — ptable задаёт смещения/размеры разделов, но базовые
   страница/блок/ECC в извлечённых константах не найдены; внешне для V7R1 — **256 МБ NAND**
   [web: balong_series]. База регистров NANDC — открытый вопрос (docs/06 §8).
4. **Имена разделов ptable** — в строках отсутствуют, дефолтная таблица лежит в
   .data‑блобе `DAT_3002c454` (разбор — docs/06 §8.1; публично имена для E3272 не найдены
   [web: негатив]).
5. **Второе ARM‑ядро/DSP** — в USBL не управляются (это burn‑образ только для модемного
   ядра); их существование — свойство платформы Balong V7 [web: balong_series].
